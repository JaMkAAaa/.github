# JaMkAAaa

Studio software z Polski. Budujemy produkty dla konkretnych branż, nie ogólne „narzędzia do wszystkiego”.

## Produkty

| Repo | Status | Opis |
| --- | --- | --- |
| [detailflow](https://github.com/JaMkAAaa/detailflow) | prywatne, v1 | SaaS dla studiów detailingowych (Next.js, Postgres, Prisma, Docker, Stripe, KSeF) |
| [Surbil](https://github.com/JaMkAAaa/Surbil) | publiczne | Osobny produkt |

## Jak tu pracujemy

1. **Nie dajemy ludziom roli Owner.** Nowy człowiek → zaproszenie do org jako Member, potem zespół.
2. **Dostęp przez zespoły**, nie przez „collaborator na jednym repo”.
   - [`core`](https://github.com/orgs/JaMkAAaa/teams/core) — write na produkty
   - [`detailflow`](https://github.com/orgs/JaMkAAaa/teams/detailflow) — maintain na Detailflow
   - [`surbil`](https://github.com/orgs/JaMkAAaa/teams/surbil) — maintain na Surbil
3. Domyślnie member **nie widzi żadnego repo** (`base permission: No permission`). Bez zespołu = zero kodu.
4. Detailflow: jedno issue = jeden PR. Epików nie implementujemy w całości. Instrukcja dla agentów: [`AGENTS.md`](https://github.com/JaMkAAaa/detailflow/blob/main/AGENTS.md).
